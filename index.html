PUBLISHED OCT 26, 2026 · SVELTIA CMS

Integration credential persistence through magic-link authentication

GHSA-2vxp-gw92-99r4 · Credited security reporter

Reported a gap in the magic-link sign-in flow where copied integration credentials could remain on a device after the associated account session ended. The maintainers published a low-severity GitHub Security Advisory, addressed the issue in v0.253.0, and credited my GitHub account, @arnabroy24, for the report.
